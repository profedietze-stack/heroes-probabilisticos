# Árbol RPG de Habilidades — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir a Héroes Probabilísticos un sistema RPG de XP con árbol de mejoras de 3 ramas (12 poderes × 3 ranks) y una barra de MP usada en batalla, sin afectar la enseñanza de probabilidad.

**Architecture:** Toda la lógica pura (catálogo de poderes, economía de XP, costos, cálculos de efectos) vive en un módulo nuevo `js/core/skills.js`, escrito para correr tanto en navegador (global) como en Node (`module.exports`) → testeable con `node`. La UI del árbol es un modal DOM (`js/ui/grimorio.js`) al estilo del inventario existente. La integración en batalla engancha en funciones ya existentes de `BattleScene.js` (`tirarDados`, `turnoMonstruo`, `victoria`, `drawPlayerBar`). Persistencia vía `state.js` + `save.js`. El árbol solo afecta modo aventura.

**Tech Stack:** Phaser 3.60 (WebGL), vanilla JS con globales cargados por loader secuencial en `index.html`, localStorage para guardado, Node para tests de lógica pura.

**Convención de testing:** No hay framework de test. La lógica pura se prueba con scripts Node (`node tests/<x>.test.js`) que usan `assert`. Las tareas de UI/Phaser se verifican con `node --check` + verificación en el preview server (no unit-testeable). Cada test pasa cuando imprime `OK` y exit 0.

**Línea roja didáctica (vale para todo el plan):** ningún poder re-lanza los dados PROPIOS del jugador para esquivar varianza; los poderes reactivos se comprometen ANTES del reveal del monstruo. Revisar en cada tarea de batalla.

/** Costo del próximo rank, o null si está maxeado/no existe. */
function nextRankCost(skills, id){
  const p = getPower(id); if (!p) return null;
  const cur = skillRank(skills, id);
  if (cur >= 3) return null;
  return p.xpCost[cur]; // cur=0 → costo rank1 en índice 0
}
/** ¿Hay XP suficiente y el poder no está maxeado? */
function canBuy(state, id){
  const cost = nextRankCost(state.skills, id);
  return cost !== null && (state.xp || 0) >= cost;
}
/** Compra el próximo rank: descuenta XP y sube el rank. Devuelve true si tuvo éxito. */
function buySkill(state, id){
  if (!canBuy(state, id)) return false;
  const cost = nextRankCost(state.skills, id);
  state.xp -= cost;
  state.skills[id] = skillRank(state.skills, id) + 1;
  return true;
}
```

/** Combinaciones de 2d12 que suman k (0 si k fuera de [2,24]). */
function combos2d12(k){ if (k < 2 || k > 24) return 0; return Math.min(k-1, 25-k, 12); }
/** Probabilidad de la suma k en 2d12 (sobre 144). */
function prob2d12(k){ return combos2d12(k) / 144; }

/** Carga de probabilidad: daño según rareza de la suma propia.
   rareza = 1 - prob; cuanto más rara la suma, más daño. */
function cargaDamage(sum, rank){
  const p = getPower('cargaProb'); const r = p.ranks[Math.max(0,rank-1)];
  const rareza = 1 - prob2d12(sum);            // 0..~1
  let dmg = 12 * rareza * r.k;
  // R3: las colas extremas (prob mínima) explotan
  if (r.boost > 1 && combos2d12(sum) <= 2) dmg *= r.boost;
  return Math.round(dmg);
}
/** Espejo de varianza: refleja daño ∝ |suma-13| × mult del rank. */
function espejoReflect(enemySum, rank){
  const mult = getPower('espejoVar').ranks[Math.max(0,rank-1)];
  return Math.round(Math.abs(enemySum - 13) * mult);
}
/** Truncar: valor fijo al que se fuerza la suma enemiga (13/11/9). */
function truncarValor(rank){ return getPower('truncar').ranks[Math.max(0,rank-1)]; }
/** Vigor: bonus de HP máximo (0 si no adquirido). */
function vigorBonus(rank){ return rank > 0 ? getPower('vigor').ranks[rank-1] : 0; }
/** Segundo aliento: HP que cura el trigger (0 si no adquirido). */
function segundoAlientoHeal(rank){ return rank > 0 ? getPower('segundoAliento').ranks[rank-1] : 0; }

/** Predicción: clasifica una suma en bin según número de bins del rank. */
function _binDe(sum, bins){
  if (bins === 2) return sum >= 13 ? 'alto' : 'bajo';
  if (sum <= 9)  return 'bajo';
  if (sum >= 17) return 'alto';
  return 'medio';
}
/** Bonus de daño si la apuesta acierta el bin de la tirada enemiga; 0 si falla. */
function prediccionBonus(apuesta, enemySum, rank){
  const r = getPower('prediccion').ranks[Math.max(0,rank-1)];
  return _binDe(enemySum, r.bins) === apuesta ? r.bonus : 0;
}
```

      const cost = nextRankCost(STATE.skills, p.id);
      const pips = '●'.repeat(rank) + '○'.repeat(3 - rank);
      const max = cost === null;
      const afford = !max && (STATE.xp||0) >= cost;
      const btn = max
        ? `<span style="color:#7a8a98">MÁX</span>`
        : `<button onclick="window.__buySkill('${p.id}')" ${afford?'':'disabled'} 
             style="background:${afford?'#3a7bd5':'#2a3142'};color:#fff;border:1px solid #6fa8ff;
             border-radius:6px;padding:4px 10px;cursor:${afford?'pointer':'not-allowed'};
             font-family:'Cinzel',serif">Subir (${cost} XP)</button>`;
      html += `<div style="display:flex;justify-content:space-between;align-items:center;gap:10px;margin:6px 0;
                   padding:8px;background:#0c1020;border:1px solid #2a3858;border-radius:6px">
        <div><b style="color:#D4AF37;font-family:'Cinzel',serif">${p.nombre}</b> 
          <span style="color:#6fa8ff;letter-spacing:2px">${pips}</span><br>
          <span style="color:#5a7888;font-family:'Poppins',sans-serif;font-size:11px">${p.desc}</span></div>
        <div>${btn}</div></div>`;
    }
  }
  return html;
}
function openGrimorio(){
  window.__buySkill = (id)=>{
    if (buySkill(STATE, id)) { saveGame(); openItemModal(_grimorioHtml()); }
  };
  openItemModal(_grimorioHtml());
}
